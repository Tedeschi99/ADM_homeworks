A git hub repository to share the homework for the ADM course at sapienza university.
The scripts.py file contains all exercises completed and submitted to HackerRank.
The printouts folder contains the screenshots of all passed exercises.
The HackerRank_Submissions.pdf has all the submissions from the HackerRank submission pages as instructed.
The HomeWork1 folder contains the unedited exercises submitted to HackerRank.
